# Step 07C｜R2R 回授控制成效：逐步理解

## 為什麼做？

07A 的 120 次**假設加工**，設定值一直是 50，MRR 逐漸高於假設目標 75。07B 只確認控制器計算正確，還沒有真正比較加工效果。07C 要把兩種情境放在**同樣的人工漂移、同樣的雜訊**下，研究調整配方有沒有改善。

> 重要：07A/07C 完全是自行產生的模型。它不是 PHM CMP 的實際調參紀錄，參數與限制也不是 Micron 工廠規格。

## 回授迴圈

1. 第 1 次加工使用設定值 `u₁ = 50`。
2. 模擬器假定：`真實 MRR = 75 + 0.65 × (本輪設定值 - 50) + 本輪人工漂移 + 本輪製程雜訊`。
3. 量測 MRR = 真實 MRR + 本輪量測雜訊。
4. **加工完成之後**，控制器才看到本輪量測 MRR 與本輪設定值。
5. 控制器依 07B 凍結的 EWMA 規則，決定**下一輪**設定值（每次最多改 1.5，設定值需在 42～58）。
6. 重複 120 次。控制器從未收到真實增益 0.65、漂移、雜訊或未來的量測結果。控制器只使用自行假設的增益 0.60。

## 這樣比較為什麼公平？

兩個情境的漂移和雜訊逐輪完全一致，而改變的只有控制策略。可更清楚隔離「有無回授控制」的影響，但仍然只是**對這個人工模型的實驗**，不能外推到真正產線。

## 指標

| 指標 | 白話意思 | 注意事項 |
|---|---|---|
| MAE from target | 每次 MRR 離 75 平均有多遠 | 越小通常代表追蹤目標更好 |
| RMSE from target | 讓較大的誤差有更高權重 | 越小越好 |
| Last-30 bias | 最後 30 次平均偏高或偏低 | 越靠近 0 代表偏差較小（看絕對值） |
| Last-30 MAE | 最後 30 次平均絕對偏差 | 與 bias 不同，不會讓正負誤差互相抵銷 |
| Setpoint changes | 真正使用過多少次新設定 | 不是越多越好，需考慮成本 |
| Total absolute adjustment | 累計改變設定值的絕對幅度 | 用來量化調整負擔 |

## 為什麼要鎖定設定？

如果看過 07C 的控制結果才調整 α 或控制增益，再拿同一 120 次資料宣稱「驗證成功」，就不是真正獨立的比較。這份程式檢查 07B 的設定及來源碼雜湊，並用完成標記防止無意義地重跑挑分數。

## 如何解釋圖？

**MRR 圖：** 兩條線代表有控制和無控制的人工量測 MRR。水平線是**假設目標**，不是工程規格或 SPC 管制線。注意回授是否能減少後半段的偏移及震盪。

**Setpoint 圖：** 固定設定保持在 50，另一條線則會依前輪量測調整。必須注意是否有碰到 42／58 上下限、是否每次改動超過 1.5。

## 面試時不能說什麼？

- 不可以說「Micron 的 MRR 改善 X%」；這是一個假設的控制器與假設的工廠響應。
- 不可以說 R2R 控制讓 PHM 真實資料的 MRR 變好；PHM 沒有真實控制回授紀錄。
- 不可以說 HGB 虛擬量測模型直接控制機台；07C 的控制器未使用 HGB，兩者是**獨立示範**。
- 不可以用 07C 生成的 artificial drift/noise 當成真實故障或真實產品良率。
