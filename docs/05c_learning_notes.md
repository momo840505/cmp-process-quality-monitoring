# Step 05C — 感測訊號「有沒有活動」和「活動時數值大小」有什麼差別？

## 這一步想解決的問題

Step 05B 算出某個感測器有多少百分比的紀錄不是 0。但即使兩片晶圓的非零比例都一樣，非零紀錄的數值仍可能差非常多。

例如兩片晶圓在 Code 4 的研磨液流量 A，各有 100 筆、其中 80 筆非零：

- 晶圓甲：非零時流量中位數 2.2
- 晶圓乙：非零時流量中位數 8.5

這兩片的活動比例相同（80%），但活動期間的典型流量不同。以上數字是教學示例，不是原始資料個案。

## 本次只做探索性篩選（不是故障分類）

1. **只用 Training Stage A**：沿用 Step 05B 的 reference / later 分組；沒有使用 MRR，也沒有讀 Test 或 Validation。
2. **逐個匿名 Code**：同一代碼才互相比較，不混合不同代碼或不同製程階段。
3. **只看非零數值中位數**：每片晶圓－代碼至少有 10 筆非零紀錄，且非零比例至少 10%，才有資格被這個特徵監控；若不足，狀態是「不適合評估」，不是「正常」。
4. **計算參考範圍**：只從 reference 中完整代碼且無同時間衝突的樣本，取非零數值中位數的 1% 到 99% 分位數。
5. **拒絕參考不夠可靠的特徵**：若可用 reference 少於 60 筆、不同值少於 10 種、或 1%–99% 區間太窄（相對寬度 <=1%），這個「代碼 × 特徵」不建立範圍。
6. **後段資料比較**：只檢查已建立參考的代碼與特徵；偏離後紀錄是哪一類（壓力、研磨液、旋轉）。
7. **兩類以上同時偏離才列入候選清單**：是事先規定的探索性規則，不是研究證實的故障警報標準。

## 輸出圖要如何閱讀

- **參考可用性熱圖**：顯示哪個 Code 的哪項訊號，資料足以建立本次篩選參考。`skip` 不代表那個感測器故障。
- **後段偏離數量圖**：單類偏離與兩類以上偏離的紀錄數。數字是「晶圓 × 代碼紀錄數」，不是唯一晶圓數，也不是真實不良率。

## 注意限制

- 匿名代碼無法證明是特定機台、腔體或 Recipe。
- 零值可能有多種意義，並未證明是漏記或停機。
- 參考段不一定健康或統計穩定；分位數是探索性資料界限，不是工程規格、OOC 或警報限。
- 同時測試多個訊號容易發生偶然超出分位數的情況，不能宣稱已知假警報率。
- 這種方法等製程資料彙總後才能用，不能宣稱即時偵測設備故障。
- 如果結果只有少量候選或沒有候選，都應照實報告，不得為了製造「成果」事後修改閾值。
