# Step 06D 中文學習筆記｜為什麼只能做一次最終測試？

## 先講重點

06B 在 Validation 比較：只報 Validation 的結果。06C 再用 **Train** 內部做各種切分及特徵敏感度測試；兩步都沒有用到 Test 的目標數值。我們這次先**決定**保留 `full_66` HGB，再打開 Test 的答案算分數。

### 為什麼用 Train + Valid 重新訓練？

因為 Validation 已經完成模型選擇（保留完整 66 特徵），之後可以讓固定的模型使用更多已知樣本，前提是不再調超參數、不因 Test 分數更換方法。這次會重新計算每組中位數 Baseline，也是只從 `Train + Valid` 計算。

### 特徵和目標別弄反

X：製程期間感測器的統計資料（66 欄，每組不同代碼）；Y：研磨完成後測量的 MRR。`WAFER_ID` 是資料追溯識別碼，不是拿來預測的數字。`mrr_review_gt_1000` 是根據答案算的審查標記，只能評估後做報告，不能訓練。

### 實際完成了什麼？

對每個代碼組先產生一個 Baseline 及 HGB 模型，再使用**同一組**內部 Test 進行公平比較。最後輸出逐片的實際、預測、誤差，並保存模型檔及固定設定。若成績不理想，也必須保留，不可以看完分數再改模型、當作沒有用過 Test。

### 最終結果的正確說法

只能說『在 PHM 公開資料的內部晶圓切分測試中，模型 MAE 從多少改善到多少』。不可以說『實際半導體工廠良率改善了幾 %』。
