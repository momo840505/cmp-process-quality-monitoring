# Step 07B 學習筆記：為何要把控制器跟模擬器分開？

## 1. 上一輪量測回饋下一輪

前一步用固定設定值 50 加工 120 次，目標 MRR=75。在假設有漂移的情境下，後 30 次的平均量測 MRR 約高於目標 4.63 個單位。這個數字來自**虛構製程**，並非工廠的品質偏移。

R2R（Run-to-Run）不需要直接控制每一秒的機台訊號；它以完成一次加工、取得量測後，估計下一次應該如何調整為核心。**測量可能有時間延遲**，所以本示範假設完成第 t 次加工後，立刻可以取得第 t 次 MRR，然後才調整第 t+1 次設定。

## 2. 我們採用的教學控制公式

假設虛構製程近似：

`measured_MRR_t = target + gain_true * (setpoint_t - nominal) + disturbance_t + process_noise_t + metrology_noise_t`

模擬器有一個真實（隱藏）增益 0.65，但**控制器不知道它**，僅假設（例如來自假設性的校正）增益為 0.60。不能把模擬器的 hidden drift 或真正的 gain 值交給控制器。

控制器在第 t 次結束後得到量測 `y_t` 及這次實際設定 `u_t`，先估計偏移：

`raw_bias_t = y_t - target - estimated_gain*(u_t - nominal)`

再用 EWMA 平滑：

`estimated_bias_t = (1-alpha)*estimated_bias_(t-1) + alpha*raw_bias_t`

最後計算下次理想設定：

`ideal_u_(t+1) = nominal - estimated_bias_t/estimated_gain`

而實際採用的 `u_(t+1)` 必須符合「一次最多變動 1.5」以及整體 [42, 58] 的**教學限制**。這些限制不是任何真實設備的操作規範。

## 3. 手算例子（最重要）

第 1 次：已完成加工，套用設定 `u_1 = 50`，量測 `y_1 = 78`。

偏移原始觀察 `78 - 75 - 0.60*(50-50) = 3.0`。

原本偏移估計=0，取 `alpha=0.35`：`b_1 = 0.65*0 + 0.35*3 = 1.05`。

理想第 2 次設定 `50 - 1.05/0.60 = 48.25`。

但是我們事先約定一次最多只能調整 `1.5`：從 50 最多降到 **48.5**。

**結論：第 1 次仍使用 50，第 2 次才可以用 48.5。**

## 4. 控制不是越頻繁、越大幅度就越好

感測雜訊會讓量測 MRR 高高低低，若每次完全照差值大幅調整，有可能反而造成來回振盪。EWMA 做平滑，設定值約束減少激烈調整；但它們不保證可用於任何設備，也可能導致反應太慢。07C 應同時比較目標偏差、後段偏移、設定值調整次數與幅度，避免只追求單一指標。

## 5. 什麼可以、什麼不可以宣稱？

**可以宣稱：** 已建立具有因果順序、EWMA 偏移估計及設定值約束的模擬 R2R 控制器，程式也有單元測試驗證。

**不可以宣稱：** 已導入真實 CMP 設備、已透過虛擬量測 HGB 自動調整機台、已實際改善 Micron 產線 MRR、或確認任何工廠安全界限。

**還未完成：** 控制器是否真的改善假設製程的 MRR，要等 Step 07C 用一模一樣的擾動與雜訊做公平比較。
